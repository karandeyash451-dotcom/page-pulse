# Page Pulse

A website auditing tool that analyzes webpages and provides key SEO and accessibility metrics.

## Features

- HTTP Status Check
- Response Time Measurement
- Page Title Extraction
- Meta Description Analysis
- H1 Count
- Missing Alt Image Detection
- Word Count
- SEO Score

## Tech Stack

Frontend:
- React
- Axios

Backend:
- Node.js
- Express
- Axios
- Cheerio

## Installation

### Backend

npm install
npm run dev

### Frontend

npm install
npm run dev

## Design Decisions

1. Used Cheerio for fast HTML parsing.
2. Added URL validation before making requests.
3. Added timeout handling for better reliability.
4. Added SEO Score as an additional feature.
